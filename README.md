# game5 — 숫자체스: 합창 대작전

초등 5~6학년 '약수와 배수'를 다루는 롤토체스식 숫자 오토배틀러. 지금은 **5주차 + 2단계(온라인 대결·랭크 티어) + 3단계** 단계입니다. 혼자 하기(컴퓨터 쉬움·보통·어려움, 친구 유령), 튜토리얼, 수학 수첩, 들어가기·기록, **온라인 대결(방 목록 → 2~4명 → 등수대로 점수, 브론즈 ~ 챌린저 9티어, 랭킹)**, 그리고 3단계 **짝꿍 팀전 2:2 · 숫자 마법 카드 20장 · 이번 주 규칙 10가지 · 관전 · 리그 꾸미기(칭호·판 테마) · 선생님 학습 지표**가 됩니다.

## 실행

```bash
npm install
npm test             # 단위 테스트(수학표, 노래 값, 결정성·대칭, 합창·다이아·멈춤·분열)
npm run dev          # http://localhost:5173/play.html — 게임(서버 없이 혼자 하기), /dogam.html — 캐릭터 도감, /balance.html — 덱 대 덱 자동 대전
npm run cf:dev       # http://127.0.0.1:8787 — Cloudflare 서버까지(들어가기·기록·친구 유령). 켜 두면 npm run dev 화면에서도 /api가 이어짐
npm run balance      # 밸런스 리포트(터미널). --quick 빠르게, --out design/balance-report.md 저장
npm run battle -- "대합창" "다이아 독창"   # 두 덱의 전투 글자 로그 (--basic 이면 기본 공격도)
npx tsx tools/tune.ts tools/variants.json --mid   # 수치 조정 실험 비교
npx tsx tools/gen-tables.ts > design/수치표.md    # 수치표 다시 만들기
npx tsx tools/ai-sim.ts 80          # 컴퓨터끼리 전체 판: 난이도별 순위, 2인 맞대결, 카드 출전
npx tsx tools/ai-sim.ts 140 --decks # 어려움 4명에게 덱 고정: 실제 경제 속 덱 세기(중반 밸런스)
npx tsx tools/ai-sim.ts 120 --decks --rule=prime  # 이번 주 규칙 하나를 켜고 덱 세기(규칙 id는 src/game/magic.ts)
npx tsx tools/ai-sim.ts 240 --magic # 마법 카드마다 평균 순위(아무 카드나 고르게 해서 비교)
```

## 배포 (Cloudflare 무료 플랜, 구구팡·구구단 디펜스와 같은 방식)
서버는 Cloudflare **Workers + Durable Objects(SQLite)** 로 동작합니다. (Pages가 아니라 **Workers**로 만들어야 합니다.)

1. Cloudflare 대시보드 → **Workers & Pages** → **Create application**
2. **Import a repository**(GitHub 저장소 가져오기)를 고르고 `game5` 저장소를 선택
3. 프로젝트 이름은 `numberchess` (`wrangler.jsonc`의 name과 같아야 함), 배포 명령은 기본값 `npx wrangler deploy` 그대로 두고 **Deploy**
   - 게임 화면 만들기(`npm run build`)는 `wrangler.jsonc`의 `build.command`로 배포 명령이 알아서 먼저 합니다.
4. 끝나면 `https://numberchess.<내 계정 subdomain>.workers.dev` 주소로 접속합니다.

`main` 가지에 올라오면 자동으로 다시 배포됩니다(대시보드 **Settings → Build → Branch**, 기본 `main`). 주소가 안 열리면 **Settings → Domains & Routes**에서 `workers.dev`를 **Enable** 하세요.
`wrangler.jsonc`에 저장소 설정이 모두 들어 있어서 따로 데이터베이스를 만들 필요가 없습니다.

**무료 한도(하루, 같은 계정의 다른 게임과 함께 씀)에서 숫자체스가 쓰는 양**
- 서버 요청: 페이지 열 때 1번(들어가 있을 때만), 들어가기 1번, **한 판 끝날 때 1번**(기록 + 본 말풍선 + 친구 유령을 한꺼번에), 튜토리얼 끝 1번, 친구 유령과 시작할 때 1번. 판 도중에는 0번
- 데이터베이스: 한 판 끝에 읽기 약 2줄 · 쓰기 기록 1줄 + 유령 1줄(+색인). 유령 정리(학교마다 최근 40판)는 10판마다 한 번. 대략 하루 1만 판 넘게 버팀
- 관전: 구경꾼 한 명당 WebSocket 하나, 라운드마다 결과 한 번 받음(서버 계산 없음). 학습 지표는 선생님이 열 때만 1번
- 온라인 대결: 방 목록은 그 화면이 열려 있을 때만 5초마다 1번(최대 10분). 게임 중에는 WebSocket 하나로 **라운드마다 내 보드 1번** — 4명 12라운드 한 판에 서버로 가는 말 약 50번, 저장 약 70줄, 끝에 점수 저장 1번씩. 방 서버(Room)는 라운드 사이에 잠들어서(Hibernation) 실행 시간도 적게 씀. 한 판이 끝나면 10분 뒤 방 기록을 지움
- 게임 계산(상점·전투·컴퓨터)은 모두 브라우저에서 해서 서버 시간은 거의 안 씀
- 한도가 차면 들어가기·기록만 멈추고, 혼자 하기는 그대로 됩니다

**휴대폰:** 세로 화면(360~430px)에 맞춘 배치가 따로 있습니다. 위 막대는 두 줄로 붙어 있고, 가문·직업은 한 줄 요약(누르면 설명 카드, 아래로 내리면 전체 설명), 상점은 옆으로 넘기기, 친구·돌을 고르면 아래에 작은 줄만 떠서 판을 가리지 않습니다([자세히]로 큰 설명). 전투는 한 화면에 꽉 차게(박자 줄 24칸 × 2줄). 가로 휴대폰·태블릿은 넓은 배치에서 전투만 크게 보여 줍니다.

**온라인 대결(랭크):** 처음 화면 → ⚔️ 온라인 대결 → ⚡ 빠른 입장(사람이 많은 방 먼저, 없으면 새 방) · 방 만들기(12라운드 / 짧은 판 8라운드) · 목록에서 들어가기. 사람이 2명 모이면 1분 뒤, 꽉 차면 5초 뒤 자동 시작(방장은 먼저 시작 가능). 빈자리는 컴퓨터(보통)가 채우고(방장 기기가 대신 둬서 서버 계산 없음, 방장이 끌 수 있음), 점수는 **사람끼리 등수**로만 정해요. 감정 스티커 8개(자유 글 없음), 새로고침해도 하던 판으로 돌아와요.
방 목록은 모든 학생·선생님이 함께 써요(우리 학교 방에는 표시만 붙음). 상점·골드·돌은 각자 화면에서 하고, 준비 완료를 누르면 보드가 서버로 가요. 시간이 끝나면 그때 판으로 자동 준비 완료. 끝난 등수대로 점수(2명: +60 · −10 / 3명: +65 · +30 · −10 / 4명: +70 · +45 · +15 · −10, 꼴등만 조금 잃고 브론즈는 그것도 절반)를 받고, 300점마다 티어가 오릅니다. 판을 많이 못 하는 학생들을 위해 **2명 판에서 반만 이겨도 12판이면 한 티어**가 오르도록 맞췄습니다(브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 다이아몬드 → 마스터 → 그랜드마스터 → 챌린저). 컴퓨터·유령 판은 연습이라 점수가 바뀌지 않아요.

**3단계(모두 혼자 하기·온라인에서 같이 됨)**
- **이번 주 규칙:** 한국 시간 월요일 0시마다 10가지 중 하나로 바뀜(합창 축제, 다이아 주간, 세모 방패, 하이파이브, 짝꿍, 부자, 뜨거운 박자, 손잡기, 돌 풍년, 저금). 처음 화면·위 막대에 보이고, 그 주 모든 판에 똑같이 적용. 한 규칙이 한 덱만 너무 세지 않게 규칙마다 덱 고정 시뮬레이션으로 맞춤(다이아 주간에 다이아 독창 평균 2.09위 → 1.91위 정도의 '주제 주간' 차이).
- **숫자 마법 카드(20장):** 12라운드 판은 3·6·9라운드, 짧은 판은 2·5라운드에 3장 중 1장(경제 1장·전투 1장은 꼭 섞임). 경제 7장(5골드, 레벨업 3골드, 친구 선물, 돌 주머니, 공짜 새로고침, 저금 왕, 무대 준비) · 가문 문장 5장(그 가문 친구 수 +1~2) · 전투 8장(지휘봉, 공약수 악수, 몸풀기 방패, 튼튼한 몸, 힘 훈련, 뜨거운 노래, 큰 수의 힘, 끝까지 버티기). 카드마다 평균 순위 2.3~2.7(2.5가 보통)로 맞춤 — [마법 카드 리포트](design/magic-report.md). 온라인에서는 고른 카드가 보드와 함께 서버로 가고, 서버가 그 라운드까지 고를 수 있는 장수인지 검사.
- **짝꿍 팀전 2:2:** 혼자 하기(나 + 컴퓨터 짝꿍 vs 컴퓨터 2명) 또는 온라인 방에서 [👯 짝꿍 팀전] 켜기(4자리, 빈자리는 컴퓨터). 늘 상대 팀과만 싸우고, 팀 메달 합으로 이김. 둘 다 이긴 라운드는 한 명당 메달 +1. 라운드마다 친구 1명을 짝꿍에게 보낼 수 있음(대기석이 차 있으면 그 값만큼 골드). 점수는 이긴 팀 사람 = 1등, 진 팀 = 2등(2명 표).
- **관전:** 로비 아래 '지금 하는 판'(30분 안)을 누르면 구경. 지난 라운드부터 모든 대결을 같은 엔진으로 다시 계산해 보여 줘서 서버 계산이 없음. 구경꾼도 감정 스티커를 쓸 수 있고, 판 위에 '👀 2' 처럼 구경꾼 수가 보임.
- **리그 꾸미기:** 🎨 꾸미기에서 칭호(튜토리얼, 첫 1등, 10판·50판, 4중창·대합창, 3성, 도감 20·25명, 변신 10가지, 온라인 5판, 티어마다) 하나를 이름 옆에 달고, 판 테마 9가지(보라 무대 → 황금 무대, 가 본 최고 티어로 열림)를 고름. 게임 힘에는 영향 없음. 서버가 열린 것만 저장.
- **선생님 학습 지표:** 선생님 계정의 처음 화면에 📊 학습 지표 — 우리 학교 학생마다 판 수·1등·티어·튜토리얼과 퀴즈 점수·본 수학 말풍선·최고 합창·도감·3성·변신 수·마지막 접속. CSV로 내려받기.

**들어가기:** 학교(검색해서 고르기, `public/data/schools.json`은 구구팡과 같은 NEIS 목록·학교 코드) + 닉네임 + 숫자 4자리. 비밀번호는 PBKDF2 해시, 10번 틀리면 10분 잠금, 같은 기기는 자동으로 들어가짐(계정당 기기 10개). 계정은 게임마다 따로 저장되지만 규칙은 다른 게임과 같습니다.

## 구조

- `src/engine/` — 게임 엔진(순수 TypeScript, 화면과 분리 → 2단계 Durable Object가 그대로 씀)
  - `math.ts` 수학표(가문, 약수, 분열 짝, 숫자 돌) · `data.ts` 캐릭터·밸런스 수치(**수치의 기준**) · `battle.ts` 결정적 박자 전투 · `log.ts` 글자 로그 · `rng.ts` 시드 난수
- `src/game/` — 한 판의 규칙(상점·카드 풀·경제·레벨·합체·라운드·몬스터·메달·보상)
  - `items.ts` 숫자 돌·보물 끼우기(칸 2개, 두 번째는 6라운드), 지금 숫자, 가문 세기, 미리보기(3줄 + 30박)
  - `bot.ts` 컴퓨터 쉬움(똑딱이)·보통(척척이)·어려움(번뜩이)
  - `magic.ts` 이번 주 규칙 10가지·숫자 마법 카드 20장(전투 효과는 `engine/battle.ts`의 TeamMods)
- `src/ui/`, `play.html` — 게임 화면(가문·직업 판 늘 펼침, 두 겹 카드, 누르기→누르기 / 끌어 놓기, 상대 판 구경)
  - `art/` 캐릭터 그림(몸 = 캐릭터·숨은 숫자, 옷·무기·받침 = 직업, 보석 = 가문) · `battle-view.ts` 박자 전투 장면(박자 줄, 합창, 말풍선, 다음 합창 예고) · `sound.ts` 숫자 음·화음(Web Audio) · `insight.ts` 결정적 장면·팁·칭찬 배지
  - `dogam.html` 캐릭터 도감(25명의 모습·숨은 숫자·노래)
- `src/game/tutorial.ts` — 튜토리얼 대본(하나쌤 34단계, 고정 상점·몬스터, 퀴즈)
- `src/net/api.ts`, `src/ui/login.ts`, `src/ui/tips.ts` — 서버 연결·들어가기 상자, 처음 보는 순간 말풍선·수학 수첩
- `src/shared/` — 학교 검색·닉네임 규칙·비속어 거르기(브라우저와 서버가 함께, 구구팡과 같은 규칙)
- `worker/index.ts`, `wrangler.jsonc` — Cloudflare 서버(들어가기·기록·도감·친구 유령·방 목록·랭크 점수·랭킹)
- `worker/room.ts` — 온라인 대결 방(방마다 Durable Object 하나, 라운드마다 보드를 모아 결과를 정함, 마감 알람)
- `src/shared/rank.ts` 등수 점수·티어 · `src/shared/online.ts` 서버와 화면이 주고받는 말 · `src/shared/cosmetics.ts` 칭호·판 테마 · `src/net/room.ts` 방 연결(끊기면 다시 잇기, 구경꾼 연결)
- `src/sim/` — 밸런스 측정(대표 덱 파워 지수, 무작위 덱 필드)
- `src/balance/`, `balance.html` — 브라우저 측정 페이지(Web Worker)
- `tests/` — Vitest
- `tools/` — 밸런스 리포트·전투 로그·조정 실험·수치표 생성 CLI
